# 🐾 Chiron Web

Frontend (SPA + PWA) de **Chiron**, el SaaS multi-tenant de gestión para veterinarias.
Construido con **React + Vite + TypeScript**; consume la API REST del backend .NET.

> El nombre viene de *Quirón (Chiron)*, el centauro sabio de la mitología griega, maestro de la medicina.

- 🌐 **Backend en producción:** https://chiron-vet-production.up.railway.app
- 📦 **Backend (repo):** https://github.com/JonYDM/chiron-vet.git

---

## Estado

🚧 En construcción. Ver la planeación completa en [`docs/PLANEACION.md`](./docs/PLANEACION.md).

## Stack

React 18 · Vite · TypeScript · Tailwind CSS · shadcn/ui · React Router · TanStack Query · PWA

## Diseño

Paleta **"Visión Canina"**: identidad basada en cómo perciben el color las mascotas
(azules y amarillos, los tonos que perros y gatos sí distinguen). Lenguaje de diseño
inspirado en Nubank (feedback claro, microanimaciones) y estética limpia estilo Apple/Material.

## Metodología

Kanban + Scrum · Git Flow simplificado (`main` + `feature/*`) · Conventional Commits ·
push por historia de usuario.

## Desarrollo

```bash
npm install
npm run dev
```

La configuración de la app y variables de entorno se documentan conforme se implementan.
